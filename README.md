# Study Assistant Android App

A native Android application developed using Kotlin and Jetpack Compose to assist students with study workflow and task organization.

## Features
- **Modern UI:** Built entirely with Jetpack Compose for reactive layout rendering.
- **Navigation Architecture:** Multi-screen navigation implementation.
- **Task Management:** Core logic for tracking study routines and schedules.

## Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **IDE:** Android Studio
- **Build System:** Gradle (Kotlin DSL)
